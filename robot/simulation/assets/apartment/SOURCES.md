# Apartment scene: sources and licenses

Generated by robot/simulation/apartment.py --fetch --build. The generated
apartment_*.xml files in this directory are project source (edit the builder,
not these files); the model and texture assets they reference are downloaded
into the ignored .cache/simulation-assets/ on the machine that ran --fetch.

## Third-party assets (all CC0)

Furniture models and surface textures come from Poly Haven
(https://polyhaven.com), license CC0
(https://creativecommons.org/publicdomain/zero/1.0/), "Powered by Poly Haven".
Per-item pages and per-file SHA-256 hashes for the verified downloaded revisions
are recorded in [manifest.snapshot.json](manifest.snapshot.json). The builder
writes the current cache manifest to `.cache/simulation-assets/apartment/manifest.json`.
Compare source-file hashes to the snapshot after a fresh fetch; upstream assets
can change. Derived-file hashes also depend on the conversion library versions.

Models: sofa_03, dining_chair_02, small_wooden_table_01,
modern_coffee_table_01, side_table_01, potted_plant_04,
modern_ceiling_lamp_01, hanging_picture_frame_01, hanging_picture_frame_02,
wall_clock, ceramic_vase_01, painted_wooden_cabinet.

Textures: white_plaster_02, herringbone_parquet, floor_tiles_06,
long_white_tiles, marble_01, oak_veneer_01, wool_boucle.

## Robot model

go2.xml and its meshes come from google-deepmind/mujoco_menagerie
(unitree_go2), pinned at commit 8161bba264d7fa7c99ca301e91e7fb44737676ad,
license: https://github.com/google-deepmind/mujoco_menagerie/blob/8161bba264d7fa7c99ca301e91e7fb44737676ad/unitree_go2/LICENSE
(stored in the ignored .cache/menagerie/, never copied into this repository).

## Project-owned

Capsule residents, procedural textures (shirt_red, shirt_teal, trousers_navy,
trousers_grey, linen, window_view, art_print) and the scene layout itself are
generated by robot/simulation/apartment.py; no third-party source.

## Fresh checkout

1. Clone the pinned menagerie per `robot/simulation/README.md`.
2. Run `.cache/dimos/.venv/bin/python robot/simulation/apartment.py --fetch`
   (network: Poly Haven CC0 into the cache; requires NumPy, Pillow, trimesh).
3. Run `.cache/dimos/.venv/bin/python robot/simulation/apartment.py --build`
   (offline: writes the scene XMLs; requires MuJoCo).
