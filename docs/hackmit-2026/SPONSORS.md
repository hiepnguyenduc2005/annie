### Espressif Systems

- **Offer:** ESP Private Agents — a self-hosted, multi-modal AI agent platform for IoT device makers to deploy AI agents inside their own AWS environments. Attachment-described features:
  - Ready-to-use agent runtime (no need to build an agent backend from scratch on AWS Bedrock or other LLM services).
  - Multi-modal support: native voice and text interaction.
  - Pluggable tools: Local Tools for device control, MCP Tools for external APIs and cloud services.
  - Unified dashboard: configure system prompts, test responses, monitor usage.
  - Flexible integration: web app, mobile app, or physical device.
- **Quota:** each team's quota increases from 200K to 2M one day before the hackathon and stays at that level for the hackathon's duration. Requests for more go through the Discord channel (per attachment).
- **How to access:**
  1. Go to [https://agents.espressif.com/](https://agents.espressif.com/) and click "Manage Agents".
  2. Under "Need an account?", click "Sign up" and complete registration.
  3. Sign in with the new account.
  4. Click the profile icon (top-right) and select "Profile".
  5. Under Account Details, copy the "User ID".
  6. Submit that User ID in the form shared by Espressif or the HackMIT team.
- **Docs and announcement:**
  - Announcement: [ESP Private Agents announcement](https://developer.espressif.com/blog/2025/12/annoucing_esp_private_agents_platform/)
  - Documentation: [https://docs.agents.espressif.com/#get-started](https://docs.agents.espressif.com/#get-started)
